Golden Base（金底）、金馬騮與褪色魚

買一尾黑黑的小魚，等上幾個月，最後得到一尾金色的魚。這個褪色過程正是 Golden Base 最大的魅力，也是許多玩家從這裡入門的原因。

「Golden Base」是什麼意思

Golden Base（金底）是馬來西亞羅漢魚繁殖熱潮中誕生的創始家族之一，在大多數花羅漢（羅漢魚）的歷史記載中，都和 Kamfa（金花）與 Zhen Zhu（珍珠，ZZ）並列。成魚是溫暖的金色到黃色，臉部、胸部與頭瘤（kok）常帶有橘色或紅色，體側可能有、也可能沒有一排深色的「花紋」。

這個家族特別的地方，在於牠們變成金色的過程。Golden Base 幼魚通常會先變成炭灰色或近乎全黑，接下來幾個月再逐漸褪去黑色，讓底下的金色透出來。會這樣變化的魚稱為褪色魚（faders），在一般魚店的日常用語裡，「Golden Base」和「褪色魚」幾乎可以互換使用。

你會看到的名稱

Golden Base、GB、褪色魚（fader）、Golden Trimac 和 Golden Monkey，都會出現在金色羅漢魚的標籤上。這些名稱彼此重疊，賣家的用法也不一致。

嚴格來說，「褪色魚」描述的是一種變化行為，而不是一個品系。玩家反映好幾個品系都有會褪色的魚，而 Golden Base 最好理解為「最後褪成金色或橘色的褪色魚」。你也會看到 Golden Trimac，早期的玩家文章把它描述為一種較原始的雜交，長大後看起來像金紅色的三間鯛（trimac）。這些名稱之間如何對應，可以先從我們的品系總覽和繁殖頁面上的品系表看起。

褪色過程，一個月一個月看

沒有兩尾褪色魚是照同一個時間表變化的，但玩家描述的大致順序相當一致：

  1. 魚苗與小幼魚

    這時的魚看起來和大多數羅漢魚苗一樣：灰色到棕褐色，帶有深色橫紋或斑塊，以及一點點早期的珠點。在這個階段，未來的 Golden Base 很難和其他寵物級羅漢魚區分。

  2. 變黑

    隨著幼魚長大，許多魚會越變越暗，直到大半個身體呈煙灰色或黑色。新手主人常以為出了什麼問題。但對褪色魚來說，這個變黑的階段是意料之中的。

  3. 黑色開始褪去

    金色或橘色的斑塊出現並擴散，每尾魚的順序都不同。有一段時間魚看起來斑斑駁駁、深淺不均，這是正常且暫時的。

  4. 成魚體色定型

    大部分黑色都褪掉了，留下黃色、金色、橘色或紅色。有些魚會保留一排清楚的花紋，有些則幾乎失去所有圖案。

要花多久時間？玩家反映，一尾魚從開始到褪完，短則約一個月，長則超過兩年，也有少數魚會卡在半途很久。「幾個月」是最常見的答案，但唯一可靠的建議就是耐心。年輕的魚通常比年紀大的魚變得快。

不必強求

沒有任何飼料或添加劑能確實誘發褪色。良好的水質和正常的飲食，就能讓魚依照自己的步調完成。

褪色結束後，顏色也可能繼續變化。主人常反映 Golden Base 的紅色在幾個月內變淡成橘色。只要魚吃得下、活力正常，這通常是發育的一部分，而不是退化。

褪色魚為什麼會變色

目前沒有人直接研究過羅漢魚的褪色現象，但在最常被列為羅漢魚祖先之一的魚身上，有一個相當接近、記錄完善的例子。部分紅魔鬼（Midas cichlid）一開始是一般的灰色橫紋外觀，之後會失去黑色素細胞，變成金色甚至白色；我們的起源頁面也把牠列為羅漢魚金色與橘色調的可能來源。2013 年發表於 BMC Genomics 的一項研究描述，這種變化可能從幾個月大到好幾歲之間的任何時間開始，過程不均勻，有時還會留下持續多年的深色斑塊。

這幾乎就是羅漢魚玩家所描述的褪色魚：開始時間不一、中間階段斑駁、偶爾停滯。合理的推測是（但尚未證實），Golden Base 血統帶有類似的性狀，而繁殖者一再留下褪得最亮麗的魚，讓這個性狀更加集中。玩家也指出，另一群祖先 Vieja 屬慈鯛中，有些也要很久才會長出成魚體色。

這對你的意義是：變黑的階段本來就是這種魚的一部分，不是品質問題；而購買時仍然黑黑的魚，就是在賭牠底下的顏色。

金馬騮屬於哪一類

Golden Monkey（金馬騮）這個名字有兩種身分，這也是它讓人如此混淆的原因。

最初的品系

  • 玩家記載中，是一個獨立、備受珍視的馬來西亞品系，而不只是單純的褪色魚
  • 讓人印象深刻的是濃郁的體色、頭部濃密的珠點、厚實圓潤的臉和內凹的眼睛
  • 就是我們起源年表中提到、創下成交紀錄的那尾魚所屬的品系
  • 普遍認為很難穩定繁殖出一樣的魚，連培育者本身也做不到

今日標籤上的名稱

  • 常被籠統地用來稱呼血統混雜的金色、黃色或橘色羅漢魚
  • 在市面上與 Golden Base 高度重疊
  • 保留在其他名稱之中：Malau 和 Kamalau 都源自粵語的「馬騮」（猴子）
  • 很少有任何文件能證明與最初的品系有關

正因如此，我們自己的品系表才會把 Golden Base 和 Golden Monkey 放在同一列。如果賣家為一尾「金馬騮」開出高價，請問清楚對方的意思：是有明確親魚的命名品系，還是只是一尾金色的魚。從這段歷史發展出來的「猴臉」品系，請看我們的 Kamalau 指南。

為什麼 Golden Base 常是第一尾羅漢魚

有人來店裡想買第一尾羅漢魚，又不想花比賽級魚的價錢時，聊到最後常常就是選 Golden Base。原因很實際：

  • 強健。Golden Base 以體質強壯、飼養寬容聞名，很能包容第一次養大型慈鯛時的摸索過程。
  • 平價。牠們通常比同樣大小的 Kamfa、SRD 或 Thai Silk（泰絲）便宜。各品系的價格比較，請看我們的羅漢魚價格指南（英文）。
  • 頭瘤不差。通常比不上頂級 Kamfa，但許多公魚能長出很像樣的頭瘤。
  • 褪色本身就是樂趣。看著一尾魚在幾個月內從炭灰色變成金色，會讓人一頭栽進去。感覺就像不用買新魚，也能得到一尾新魚。
  • 完整的羅漢魚個性。牠們和昂貴的品系一樣愛和人互動，而這正是大多數人真正想要的。為什麼這一點很重要，請看我們的把羅漢魚當寵物。

但要提醒一點：「適合新手」不代表體型小或性情溫和。Golden Base 一樣會長成 12 吋（30 公分）以上的慈鯛，成魚需要至少 75 加侖（約 284 公升）的魚缸，必須單養，而且可能和任何羅漢魚一樣兇。請先用我們的魚缸設置指南（英文）規劃好魚缸，再去買魚。

選購與飼養褪色魚

因為你買魚的時候，牠的成魚體色往往還沒出現，所以請根據現在看得到的部分來判斷：

  • 先看行為。一尾活潑、會游到缸前、吃得很起勁的魚，比躲在角落的漂亮魚更值得押注。
  • 身體與魚鰭。挑身體厚實均勻、背部平直、魚鰭對稱、眼睛清澈的魚。這些都不會因為褪色而改變。
  • 提早出現的金色。腹部或臉部已經透出金色或橘色的斑塊，是未來體色的好兆頭。
  • 小心催出來的顏色。一尾很小的魚卻紅得發亮，可能被大量餵食增豔飼料，而這種顏色可能會掉。其他該檢查的地方，請看我們的評級指南（英文）。

飼養方式就是標準的羅漢魚照顧：溫暖乾淨、80–86°F（27–30°C）的水，定期大量換水，並依照我們的餵食指南（英文）餵食優質的主食顆粒。增豔飼料能讓已經褪完色的成魚紅色和橘色更亮，但不會加快褪色，也無法取代良好的水質。如果想親自挑一尾，歡迎到 San Diego 的 Pet Zone 看看。

關於 Golden Base 羅漢魚的常見問題

我的小羅漢魚為什麼變黑了？

如果牠是 Golden Base 或其他褪色魚，變黑是黑色褪成金色、黃色或橘色之前的正常階段。如果魚同時躲起來、不吃東西或夾鰭，請檢查水質，因為壓力也會讓任何羅漢魚變暗。

褪色魚要多久才會褪完？

通常要好幾個月，但玩家反映從約一個月到超過兩年都有。年輕的魚通常褪得比較快，有些則會在半途停一陣子才完成。

Golden Base 和金馬騮有什麼不同？

Golden Base 是金色褪色魚的廣泛家族。Golden Monkey（金馬騮）最初指的是一個特定、備受珍視的馬來西亞品系，臉部圓潤、頭部珠點濃密，但如今這個名稱常被籠統地用來稱呼任何金色羅漢魚。

Golden Base 羅漢魚適合新手嗎？

適合，牠是最常見的第一尾羅漢魚之一，因為強健又平價。但牠一樣需要專屬的大魚缸，以及和任何成年羅漢魚相同的照顧。

我可以讓羅漢魚褪色得快一點嗎？

沒有可靠的方法。褪色由基因決定，會依照魚自己的步調進行，你能做的就是保持水質乾淨溫暖，並餵食良好的主食。
